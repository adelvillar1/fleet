The owner's ruling (2026-10-16), from a comparison of what ZCode and the Hermes agent seed to new sessions: fleet's `SYSTEM_PROMPT` takes the best of both — Hermes' claim-time verification (every claim backed by tool output from this session, checked when the claim is made; "Done" = every criterion tool-verified) and execution discipline (read back after external writes, reconcile counts, act rather than describe), plus ZCode's outcome-first communication and end-turn discipline. The prompt is universal by design: repo knowledge rides recall and `docs/harness-orientation.md`, never the compiled-in constant. The identity slot is `<FLEET_HOME>/SOUL.md` (Hermes' hot-persona pattern, in fleet's own home): read per run, sanitized and bounded at 8192 characters, and when present it replaces the base while the skills and memory frames append. A delegation child inherits the parent's identity with its model. The owner can adapt `~/.hermes/SOUL.md` into it — fleet never reads the hermes file itself.
