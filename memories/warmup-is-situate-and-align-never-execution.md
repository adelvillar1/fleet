The owner's ruling (2026-11-13, after a warmup session spent 60 turns, ~10.7 minutes and 96 model calls on orientation and then announced it was "picking up the housekeeping"): *"doing a warmup is just for getting situated and align your bearings with what's going on with the project"*. A warmup is one bounded pass — branch, git state, the state surfaces (state doc, newest recap's summary, plan status lines, the ledger's open count) — reported compactly (branch and last commit, what shipped last session, what is open by names and counts, where the work is headed), ending with the ask: what do you want to work on? A fact the pass verified stays verified; the report cites it and never re-derives it. No row-by-row ledger audits, no version archaeology, no server probes, no drift scripts — a surface the ask did not name is never audited.
