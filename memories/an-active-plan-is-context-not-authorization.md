The owner's ruling (2026-11-13, spoken in the session where the agent treated a ticked-off plan as standing authorization): *"plans govern work only when I activate them or I request to continue working, a plan even if it's active is not a license to jump into work, you need to ask me if I want to do that"*. What a warmup, a status read, or any survey finds open — an active plan, an open ledger row, a deferred fix, unticked criteria — is a line in a report, never the next action. The "decide, then act" posture governs work the owner already asked for; it does not convert found state into found authorization. Executing anything needs the owner's request in this conversation.
