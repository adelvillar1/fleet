the rulepreview is the default where a human can read it

For an image, a document, a sheet, a deck or a PDF, the drawer opens on the preview — the object as a human would see it. Code and tree objects keep the code body with the breadcrumb; a fact or a deliverable keeps its own card grammar.

Where a kind has a second honest body (a sheet as its values, a markdown file as source), the mode switch carries the override. Nothing new needs a server or a network: every engine above runs inside the sandboxed frame from bytes the host hands in.

  • docx → docx-preview (vendored)
  • pdf → PDF.js (vendored)
  • md → marked + DOMPurify
  • xlsx → core reader + styles
  • pptx → PPTXjs 2.0.0 (research)
