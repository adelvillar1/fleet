# Plan: icons — one meaning per mark, on every rail

## Context

Drawing the huddles mockup's rail by hand exposed what the real rail has
been hiding. The audit of the face's icon surface
(`src/gui/assets/app.js`, `index.html`, `app.css`) found:

- **Thirteen names are declared but never drawn.** `icon()` falls back to
  `ICONS.dot` silently (`app.js:1145`), so on the main rail **huddles,
  vault and plugins — three built destinations — are the same hollow
  ring** (`GROUPS`, `app.js:275, 289, 292`). In the section rails:
  memory's needs-you, user, feedback, episodic, retired and today; skills'
  needs-you, design, curation and retired; calibration's gate,
  eval_corpus, embed_timing and lifecycle; settings' trust, schedule and
  interface. **Six of memory's ten rows and three of settings' seven ring
  the same as a missing key.**
- **One drawing for many concepts.** The clock is sessions, memory's
  archive, skills' media and calibration's turn; the folder is memory's
  project, skills' documents, calibration's consolidate and every
  workspace project; the book is the memory surface, memory's reference,
  skills' data and calibration's recall hits; the route is the router,
  skills' web, settings' models and calibration's routes.
- **Drawings that cannot read at 17px**: `workspace-history` (seven
  elements, r2.4 dots), `delegation` (six thin sub-paths), `bots` (a r1.3
  antenna, 1.5-unit eyes), `plan` (a 6×3 clip rect), `calibration` (four
  peaks over 18 units), `thinking` (a r1.8 dot in a 13px box).
- **No mark at all**: `#huddles-rail` is declared and never populated;
  plugins has no rail; bots' persona rows all wear one shared stack while
  the same entities get initials in a huddle; pane tabs are words only.
- **Dead icon code**: `GLYPHS` (`app.js:1073`), `GROUP_MARKS` (`464`), the
  `tower` drawing (never passed to `icon()`), and four `.card-row` accent
  selectors for kinds `card()` never emits.
- **The divergence the owner named**: `#rail-toggle` is a text chevron
  plus the words "collapse the rail", while the section rails' fold has
  always been a chevron alone.

**Outcome.** One table where every key is drawn, one drawing per concept,
every mark legible at 13px, no silent fallback — and the rail's collapse
control reduced to its icon. The same process as the huddles mockup: a
sheet drawn, measured and read before the code.

## The contract

- **One table.** Every key used anywhere resolves. `icon()`'s fallback
  becomes a visible `unknown` (a circled question mark): a missing key
  must look missing, never like an intentional "other" bullet.
- **`other` is a mark** (three dots) for the legitimate "everything else"
  and "declined" rows, so they stop sharing a glyph with the unknown state.
- **One stroke.** 24 viewBox, 1.6 stroke, round caps and joins. The two
  inline icons that break it (the rail menu at 1.7, send at 1.8) are
  brought to 1.6.
- **A source pin.** A harness case reads `app.js` as text, extracts every
  `icon('…')` call and every key in the icon-carrying data (the section
  maps, `GROUPS`, the rail builders), and fails on any key missing from
  `ICONS`. This is the check that would have caught all thirteen.
- **Same mark for the same concept is named.** A surface and its own
  section share a drawing (memory's book, design's artboard, a project's
  folder, the needs-you bell wherever it is the same queue).

## The rails

- **Main rail:** fifteen destinations, fifteen distinct marks.
- **Section rails:** every row gets a mark drawn for its concept. The
  shared tables (`MEMORY_SECTION_ICONS`, `SKILL_CATEGORY_ICONS`,
  calibration's op map, settings' section map) stay the only place a key
  is chosen — the sheet and the code read one list.
- **Bots:** persona rows wear their `pmark` initials (the mark huddles
  already uses); channels keeps the robot.
- **Huddles:** `#huddles-rail` is **deleted**, not filled — the huddles UX
  plan replaces that surface and its rail is the rooms column.
- **Palette:** reads the same table, so a destination's mark is the same
  in the rail and in ⌘K.
- **The groups fold.** Each group label becomes a control: a press folds
  its rows to the label — the label carries the group's needs-you count so
  nothing is hidden silently — and a second press restores them. The state
  is remembered per group across launches, and a folded group keeps its
  divider so the rail's rhythm holds. In icons mode the labels are hidden,
  so every row shows; the fold is remembered for full mode.
- **Pane tabs** stay words: a tab strip, not a rail.

## The collapse control

`#rail-toggle` becomes **the chevron alone** — an SVG chevron from the
icon set, 16px, rotating 180° in icons mode; the `#rail-toggle-name` span
is deleted; `aria-label` and `title` carry the words. `applyRail` stops
writing a label it no longer has.

## Out of scope

- Pane tabs' words, the status dots' CSS geometry, the persona/avatar
  system, and the huddles surface (its own plan, next).
- An icon font or sprite file: the drawings stay an inline SVG table.
- The transcript cards' text glyphs (`▦`, `◇`, `±`): card kinds, not
  rails; named as a follow-up if the sheet shows they read as icons.

## Risks

- **The main rail's marks change everywhere.** Every destination's icon is
  visible on every screen; the sheet is the gate, and the harness pins the
  fifteen distinct marks.
- **The section maps are the seam.** One wrong key shows as `unknown` in a
  rail the sheet did not cover; the source pin covers all of them, and the
  sheet draws every rail.
- **`dot` is used as a state mark elsewhere** (huddle rows, plugin rows).
  Its replacement is a filled bullet, so a state dot still reads; the
  unfilled ring retires.
